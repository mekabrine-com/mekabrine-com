JailBoard Setup

Install files, prepare a theme, apply it

How to set up JailBoard

  1. Install the 3 Shortcuts in JailBoard-Files.zip into the iOS Shortcuts app (App Store).
  2. Download any theme made for JailBoard.
    To verify a theme: unzip it and check for a file named JAILBOARD.txt. If present, it’s a valid JailBoard theme.
Download JailBoard-Files.zip

How to prepare a theme

  1. Run the JailBoard shortcut.
  2. Select your theme .zip file.
  3. Choose whether to start with all icons selected, then manually select/deselect app names until only the apps installed on your iDevice remain.
  4. Choose what to do next:
    • Install now, or
    • Save the completed theme to a file that anyone can tap to install later.

How to apply a theme

A. If you chose to save the completed theme to a file

  1. Tap the .mobileconfig file.
  2. Allow the download to the profile.
  3. Open Settings and tap Downloaded Profile.
  4. Tap Install, enter your device passcode, tap Install again, then tap it one more time.
  5. Check your Home Screen.

B. If you chose to install now

  1. Read the popup then tap Done or the X (the X shows on iOS 26).
  2. Allow the download of the profile.
  3. Settings should open automatically. Tap Downloaded Profile.
  4. Tap Install, enter your device passcode, tap Install again, then tap it one more time.
  5. Check your Home Screen.

How to create JailBoard themed icons

Generate icons via Shortcuts and save them to a folder
  1. Create a square icon for any app you want.
  2. Tap here and add the shortcut to the iOS Shortcuts app.
  3. Run the shortcut and immediately open the app you made an icon for (you have 5 seconds to open the app).
  4. Choose your created icon when prompted to select a photo.
  5. Choose the folder where you want the themed icons to be saved.

How to create a JailBoard theme

Package your icons so JailBoard can use them
  1. In your file manager, create a folder with your theme name. Example: Coolest-Theme
  2. Inside that folder, create a blank text file named JAILBOARD.txt
  3. In your theme folder, create a folder called ThemedIcons and move all your themed icons into it.
  4. Compress your entire theme folder into a .zip file — you’re ready to go.
