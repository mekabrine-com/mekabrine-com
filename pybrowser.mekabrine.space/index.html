Installation Instructions

1. Install Required Python Packages

Run this command in Command Prompt:

python -m pip install PyQt6 PyQt6-WebEngine pywin32 requests

Or this if it gave an error:

python3 -m pip install PyQt6 PyQt6-WebEngine pywin32 requests

2. Windows: Installing Python

Visit the official Python website:
https://www.python.org/downloads/

Download the latest version for Windows, run the installer,
and make sure to check "Add Python to PATH" before installing.
